# Skills library

Editing skills made from the breakdowns in [`breakdowns/`](../breakdowns/), with the `video-to-skill` skill.

| Skill | Made from | What it builds |
|---|---|---|
| [fast-list-talking-head-with-inserts](fast-list-talking-head-with-inserts/SKILL.md) | [tuesday-simulator](../breakdowns/tuesday-simulator/VIDEO.md) | A 60 second talking-head list video where every claim gets a picture: presenter, split inserts and full-frame diagrams at 26 cuts a minute |

To use one: copy its folder into `.claude/skills/` in the project where you edit, then ask Claude Code for an edit in that style.

Each skill is built from one video. The numbers are that video's, tagged measured, seen or inferred. Read the last section of a skill before you trust it.
